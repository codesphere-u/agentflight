### Solving the Production AI Agent Safety Gap

As organizations deploy multi-agent systems for autonomous coding, financial automation, and DevOps, they face high risks of runaway API expenditures caused by subtle loop oscillations, repeated parameter errors, and unoptimized tool schemas.

AgentFlight v1.2.0 delivers the critical control plane required for enterprise safety:
- **Zero-Credit Defense:** Calculates deterministic pre-execution price estimates and halts calls that exceed budget limits before network dispatch.
- **Runaway Loop Protection:** Identifies cyclic ping-pong states (`A -> B -> A -> B`) and halts execution before credit depletion.
- **Tamper-Evident Flight Recording:** Cryptographically records every agent decision into SHA-256 chained cassettes with automatic secret redaction.
- **Microsecond Offline Replay:** Enables engineering teams to execute comprehensive regression test suites in CI/CD at 0.08 microseconds per span with zero external network calls and zero cost.
