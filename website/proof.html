Why AgentFlight & Verified Proof

Multi-step tool-calling agents fail in ways standard HTTP mocks cannot reproduce cleanly: key-order drift across runs, silent parameter omissions on weak MCP schemas, A↔B tool oscillation loops, and $5 overnight token spikes in CI.

Created independently by Akandwanaho Ivan Alvin, AgentFlight records every step into an atomic SHA-256 cassette with API keys scrubbed automatically so teams test deterministically offline at $0.00 spend.
