questions

How does AgentFlight replay multi-step AI agents in CI with $0 token spend?

FlightRecorder captures every LLM turn, streaming delta, and MCP tool call into a canonical-JSON SHA-256 hash chain (.flight.json or .flight.jsonl) with secrets scrubbed. CassetteReplayer and the built-in pytest plugin stub matching tool calls locally in microseconds and raise TrajectoryDivergenceError when arguments drift.

What does the core Python SDK require at runtime?

Everything inside src/agentflight (recording, replay, loop circuit breaker, trajectory diffing, OpenTelemetry export, PII redaction, and the stdio MCP server) uses pure Python 3.10+ standard library only.

Can I connect AgentFlight to Claude Code, Cursor, or CI pipelines?

Yes. Run agentflight serve-mcp via uvx for local stdio workflows, connect to the hosted Streamable HTTP endpoint at https://agentflight-tau.vercel.app/mcp, or gate pull requests using agentflight ci.
